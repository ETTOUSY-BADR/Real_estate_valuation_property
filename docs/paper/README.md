# Benchmark paper

The editable manuscript is `main.tex`; references are stored in
`references.bib`. The paper imports figures from `../../visuals/benchmark/`.

Compile from the project root:

```powershell
powershell -ExecutionPolicy Bypass -File .\docs\paper\compile_paper.ps1
```

The resulting PDF is `docs/paper/main.pdf`.

The Phase 2 data-engineering addendum is `phase2_addendum.tex`. Compile it with:

```powershell
powershell -ExecutionPolicy Bypass -File .\docs\paper\compile_phase2.ps1
```

The resulting PDF is `docs/paper/phase2_addendum.pdf`.

The detailed Phase 3 external-data paper is `phase3_paper.tex`. Compile it with:

```powershell
powershell -ExecutionPolicy Bypass -File .\docs\paper\compile_phase3.ps1
```

The resulting PDF is `docs/paper/phase3_paper.pdf`. Its six publication figures
are generated by `python -m paris_avm.visualization.phase3` and stored in
`visuals/phase3/`.

The complete preprocessing and refreshed chronological model-evaluation report
is `model_evaluation_report.tex`. Generate its detailed diagnostic tables and
figures, then compile it with:

```powershell
$env:PYTHONPATH = '.\src'
python -m paris_avm.visualization.phase2
python -m paris_avm.visualization.phase3
python -m paris_avm.visualization.model_evaluation
powershell -ExecutionPolicy Bypass -File .\docs\paper\compile_model_evaluation.ps1
```

The resulting professional report is
`docs/paper/model_evaluation_report.pdf`; its dedicated figures are stored in
`visuals/model_evaluation/` and its machine-readable tables in
`reports/model_evaluation/`.

The Phase 4 nationwide manuscript is generated directly from the national
benchmark artifacts and then compiled with:

```powershell
$env:PYTHONPATH = '.\src'
python -m paris_avm.analysis.phase4_preflight
python -m paris_avm.visualization.phase4 --allow-incomplete
python -m paris_avm.reporting.phase4
powershell -ExecutionPolicy Bypass -File .\docs\paper\compile_phase4.ps1
```

The outputs are `phase4_national_report.tex` and
`phase4_national_report.pdf`. Before national training, they form an explicitly
labeled protocol/pre-benchmark edition; after training, the identical commands
insert the model comparison, paired bootstrap interval, regional table and all
empirical figures.

After the national Gold table exists, the preflight command adds an empirical
data-quality audit, leakage-safe department market clustering, two diagnostic
figures and the registered with/without-clustering ablation to the paper.

To reproduce the empirical inputs before compiling:

```powershell
$env:PYTHONPATH = '.\src'
python -m paris_avm.modeling.benchmark_phase1
python -m paris_avm.visualization.benchmark
```
